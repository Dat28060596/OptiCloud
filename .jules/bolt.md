## 2025-03-09 - [Combine Filtering and Grouping to Avoid Multiple Iterations and Map Overhead]
**Learning:** When filtering, grouping, and aggregating large datasets on the frontend, chaining multiple array methods (`filter`, `forEach`) and using `Map` structures can introduce significant memory overhead and unnecessary iterations. Using a single `for` loop with a plain JavaScript Object (`Record<string, ...>`) accumulation skips the intermediate array creation and reduces the overhead of `Map`, significantly improving performance for large data manipulation.
**Action:** When handling data transformation (filter + group) in React components, prefer a single `for` loop with POJO accumulation over chained array methods or `Map` objects, especially when dealing with potentially large arrays of items (like CostMetrics).
