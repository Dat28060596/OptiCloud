## 2024-03-20 - Set Lookups for Multi-Attribute Filtering in React useMemo
**Learning:** In applications like CostExplorer that perform multiple linear `.includes()` checks (Service, Region, Account, Tag) inside a large `.filter()` loop, the algorithmic complexity quickly becomes O(N * M) where N is dataset size and M is total active filters. `Array.includes()` was notably slower here. Converting the small active filter arrays to `Set` objects *inside* the `useMemo` block immediately before filtering reduces the time complexity to O(N) by replacing array scans with O(1) hash map lookups.
**Action:** Always convert lookup arrays to Sets when filtering large collections of data in the frontend, specifically inside `useMemo` closures so that the Sets are recreated efficiently when dependencies change.
