## 2025-02-20 - [Date Sorting Optimization and Environment Constraints]
**Learning:** Commands like `bun add` or `npm install` implicitly modify `package.json`. When operating under strict constraints forbidding `package.json` modifications, fixing TypeScript declaration errors (like missing `@types/react`) must be avoided. The optimization logic (lexicographical string comparison instead of `new Date()`) works perfectly and reliably reduces CPU execution time, but the surrounding constraints strictly block fixing peripheral dependency issues.
**Action:** Do not attempt to fix type errors by installing new dependencies if the constraints forbid touching `package.json`. Focus purely on the targeted optimization and ensure it does not introduce new type errors, leaving existing uninstalled type definitions as they are.
