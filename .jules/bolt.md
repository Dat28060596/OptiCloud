## 2024-07-18 - Single-Pass Loop Optimization for Filters
**Learning:** Chaining array methods like `.filter()` and `.forEach()` creates intermediate array allocations and causes multiple iterations over the dataset (O(N) + O(M)). In a data-heavy application like a cost explorer, this can be a significant bottleneck. Using a Map for grouping is also less efficient than using a plain JavaScript object when the keys are just strings.
**Action:** For large dataset transformations on the frontend, combine filtering and grouping into a single `for` loop (single pass, O(N)) and use a plain `Record<string, ...>` object for accumulation. This reduces memory overhead and improves performance. Always check for artifacts like `modify.py` or modified `.html` files before submitting a PR.
