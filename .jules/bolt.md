## 2025-02-24 - Efficient Date Sorting
**Learning:** Parsing `YYYY-MM-DD` date strings into JavaScript `Date` objects inside a `.sort()` function callback is extremely slow because it forces object creation on every $O(N \log N)$ comparison. However, since the dates are in ISO 8601 format, standard lexicographical string comparisons (`<`, `>`) produce the exact same chronological sorting order without any object allocation. In V8/JS engines, string comparison operators evaluate much faster than `String.prototype.localeCompare()`.
**Action:** When sorting ISO 8601 formatted date strings in arrays, always use direct string comparison (`a < b ? -1 : a > b ? 1 : 0`) instead of parsing them into Date objects (`new Date(a) - new Date(b)`) to maximize execution speed and minimize memory overhead. Ensure the string comparison avoids `localeCompare` for basic ASCII string sorts.
