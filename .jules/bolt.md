## 2024-05-24 - Optimizing filtering and grouping in CostExplorer.tsx
**Learning:** Combining filtering and grouping into a single pass using a plain JavaScript object instead of multiple passes (filter + map) significantly reduces processing time for large arrays, improving performance by ~3x (from ~21ms to ~7.5ms for 100k items). Plain object keyed access `map[key]` is also faster than `Map.get(key)`. Additionally, defining components (like `FilterDropdown`) inside the render loop causes excessive tear-down and re-renders, adding huge overhead; React components should always be extracted.
**Action:** Replace two-pass `.filter().forEach()` patterns with a single `for` loop pass that uses a plain object for grouping. Extract sub-components defined within render functions to module level and wrap them in `React.memo` to eliminate unnecessary DOM tear-downs.
